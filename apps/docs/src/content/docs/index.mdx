## Developer & Agent Quickstart

<Tabs>
  <TabItem label="For Human Developers">
    ### 1. Install Core & Adapter

    ```bash
    pnpm add @akadli/core @akadli/dz-geo @akadli/provider-shopify
    ```

    ### 2. Ingest Webhook, Trigger Voice Call & Mutate Order

    ```typescript
    import { ShopifyProvider } from "@akadli/provider-shopify";
    import { handleFinalizeOrderToolCall, buildElevenAgentsDynamicVariables } from "@akadli/core";

    const provider = new ShopifyProvider();

    // 1. Verify HMAC signature & parse order into 2026 69-Wilaya format
    const isValid = await provider.verifyWebhook(headers, rawBody, process.env.SHOPIFY_WEBHOOK_SECRET!);
    const order = await provider.parseWebhookOrder(JSON.parse(rawBody));

    // 2. Build ElevenAgents dynamic variables (currentVariant, allowedVariants, phone)
    const promptVars = buildElevenAgentsDynamicVariables(order);

    // 3. Receive tool call from ElevenLabs after call and apply store mutation
    const result = await handleFinalizeOrderToolCall(
      {
        orderId: order.orderId,
        status: "CONFIRMED", // or "MODIFIED" (finalVariant, finalCommune) | "REFUSED"
        reasonOrNotes: "Confirmed in Algerian Darja via ElevenAgents"
      },
      provider,
      { shopDomain: process.env.SHOPIFY_SHOP_DOMAIN!, accessToken: process.env.SHOPIFY_ACCESS_TOKEN! },
      order.constraints
    );
    ```
  </TabItem>

## Architectural Highlights

<CardGrid stagger>
  <Card title="2026 69 Wilayas & 1,708 Communes" icon="seti:graphql">
    Official Algerian administrative division with Arabic, French, and Arabizi fuzzy address resolution. Includes newly promoted Wilayas (59–69 like Barika, Bou Saada, Bir El Ater).
  </Card>
  <Card title="ElevenAgents Voice Orchestration" icon="rocket">
    Stateless WebRTC & SIP audio bridge. Generates Darja-tailored system prompt variables and securely validates final decisions via server-side tool calls.
  </Card>
  <Card title="Production Store Adapters" icon="puzzle">
    Ready-to-use stateless connectors for Shopify, YouCan, WooCommerce, Google Sheets (SetShop/JustSell), and Tassyir COD ERP with Ed25519 signature checks.
  </Card>
  <Card title="Local Wi-Fi Testing Sandbox" icon="laptop">
    Interactive `@akadli/playground` with a desktop dispatch center (`/admin`) and a mobile phone simulator (`/phone`) for live testing over LAN without deploying servers.
