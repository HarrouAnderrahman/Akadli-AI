## البدء السريع للمطورين ولوكلاء الذكاء الاصطناعي

<Tabs>
  <TabItem label="للمطورين البرمجيين">
    ### 1. تثبيت الحزم الأساسية ومحول المتجر

    ```bash
    pnpm add @akadli/core @akadli/dz-geo @akadli/provider-shopify
    ```

    ### 2. استقبال الطلب، إطلاق المكالمة الصوتية وتحديث المتجر

    ```typescript
    import { ShopifyProvider } from "@akadli/provider-shopify";
    import { handleFinalizeOrderToolCall, buildElevenAgentsDynamicVariables } from "@akadli/core";

    const provider = new ShopifyProvider();

    // 1. التحقق من توقيع Webhook وتحليل بيانات الطلبية وفق تقسيم الـ 69 ولاية
    const isValid = await provider.verifyWebhook(headers, rawBody, process.env.SHOPIFY_WEBHOOK_SECRET!);
    const order = await provider.parseWebhookOrder(JSON.parse(rawBody));

    // 2. بناء المتغيرات الديناميكية للمكالمة الصوتية بالدارجة (currentVariant، الولاية، الهاتف)
    const promptVars = buildElevenAgentsDynamicVariables(order);

    // 3. استقبال قرار العميل من أداة ElevenLabs وتحديث بيانات المتجر فوراً
    const result = await handleFinalizeOrderToolCall(
      {
        orderId: order.orderId,
        status: "CONFIRMED", // أو "MODIFIED" لتعديل المقاس أو البلدية أو "REFUSED"
        reasonOrNotes: "تم تأكيد الطلبية بالدارجة عبر مكالمة ElevenAgents الصوتية"
      },
      provider,
      { shopDomain: process.env.SHOPIFY_SHOP_DOMAIN!, accessToken: process.env.SHOPIFY_ACCESS_TOKEN! },
      order.constraints
    );
    ```
  </TabItem>

  <TabItem label="لوكلاء الذكاء الاصطناعي (AI Coding Agents)">
    ### ملفات السياق الفوري للوكلاء

    زوّد وكيل البرمجة بالذكاء الاصطناعي (Cursor, Antigravity, Claude Code, GitHub Copilot) بكامل سياق المشروع بضغطة واحدة:

    - **الملخص الهندسي:** [`https://akadli.me/llms.txt`](/llms.txt)
    - **السياق البرمجي الكامل والشامل:** [`https://akadli.me/llms-full.txt`](/llms-full.txt)

    ### نص التوجيه المباشر (Prompt) للوكيل

    انسخ هذا التوجيه مباشرة داخل بيئة وكيل الذكاء الاصطناعي لديك:

    ```markdown
    أنت تقوم بربط محرك تأكيد طلبيات الدفع عند الاستلام بالجزائر Akadli-AI.
    احصل على السياق الكامل من https://akadli.me/llms-full.txt والتزم بالمعايير التالية:
    1. استخدام @akadli/adapter-contract لنموذج StandardizedDzOrder و FinalizedOrderDecision.
    2. مطابقة العناوين حصرياً مع التقسيم الإداري 2026 (69 ولاية) باستخدام @akadli/dz-geo.
    3. استخدام @akadli/core لبناء متغيرات ElevenAgents وتشغيل handleFinalizeOrderToolCall.
    4. وسوم المتجر يجب أن تكون حصرياً: akadli-confirmed و akadli-modified و akadli-refused و akadli-variant-{variant}.
    5. يجب أن تبدأ ملاحظات الطلب ببادئة [Akadli-AI].
    6. لا تخترع حالات جديدة، بل استخدم فقط CONFIRMED أو REFUSED أو MODIFIED.
    ```
  </TabItem>
</Tabs>

## المزايا المعمارية الرئيسية

<CardGrid stagger>
  <Card title="التقسيم الإداري 2026 (69 ولاية و 1708 بلدية)" icon="seti:graphql">
    قاعدة بيانات رسمية كاملة مع دعم البحث الذكي غير الدقيق بالعربية والفرنسية والعربيزي. تشمل الولايات المستحدثة (من 59 إلى 69 مثل بريكة وبوسعادة وبئر العاتر ومسعد).
  </Card>
  <Card title="إدارة المكالمات الصوتية بـ ElevenAgents" icon="rocket">
    جسر صوتي بدون حالة (Stateless) عبر WebRTC و SIP. يولد متغيرات التعليمات بالدارجة الجزائرية بدقة ويتحقق برمجياً من قرارات العميل عبر دوال الخادم.
  </Card>
  <Card title="محولات جاهزة لمنصات التجارة الإلكترونية" icon="puzzle">
    تكامل مباشر مع Shopify و YouCan و WooCommerce و Google Sheets ومتاجر SetShop و JustSell ونظام إدارة طلبيات COD الجزائري Tassyir.
  </Card>
  <Card title="بيئة تجارب محلية عبر Wi-Fi (@akadli/playground)" icon="laptop">
    منصة اختبار تفاعلية متكاملة تشمل لوحة تحكم مكتبية للمدير (`/admin`) وهاتف افتراضي تفاعلي (`/phone`) للاختبار المباشر بالهاتف عبر الشبكة المحلية.
  </Card>
</CardGrid>
