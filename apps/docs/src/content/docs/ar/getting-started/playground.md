تطبيق `@akadli/playground` (الموجود في `apps/akadli-playground`) هو بيئة اختبار تفاعلية متكاملة تتيح لك محاكاة المكالمات الهاتفية للزبائن، واختبار جودة الصوت المزدوج بالدارجة الجزائرية عبر WebRTC، واستقبال الـ Webhooks دون الحاجة إلى خوادم سحابية.

## المزايا الأساسية

- **لوحة تحكم المدير المكتبية (`/admin`):** إرسال نماذج طلبيات تجريبية لجميع المنصات، وفحص البيانات المتدفقة، ومتابعة نصوص المحادثات الصوتية مباشرة.
- **محاكي الهاتف المحمول (`/phone`):** صفحة تفاعلية تفتحها على هاتفك الذكي المتصل بنفس شبكة Wi-Fi. تحاكي رنين الهاتف وزر الرد والرفض وتتصل فورياً بالوكيل عبر WebRTC.
- **دعم جميع المنصات:** دعم فوري للطلبيات الحقيقية والمحاكاة لمتاجر شوبيفاي، ويوكان، وووكومرس، وجداول جوجل، ونظام تسيير.

---

## 1. التشغيل السريع

```bash
# 1. استنساخ المستودع وتثبيت الحزم
git clone https://github.com/HarrouAnderrahman/Akadli-AI.git
cd Akadli-AI
pnpm install
pnpm build

# 2. تهيئة المتغيرات البيئية
cp apps/akadli-playground/.env.example apps/akadli-playground/.env
# أضف مفتاح ELEVENLABS_API_KEY و ELEVENLABS_AGENT_ID داخل الملف

# 3. تشغيل خادم التطوير
pnpm --filter @akadli/playground dev
```

يعمل التطبيق على العناوين التالية:
- واجهة المستخدم: `https://localhost:3000`
- خادم الـ API الخلفي: `https://localhost:3001`

---

## 2. الاختبار عبر شبكة Wi-Fi على هاتفك الذكي

1. استخرج عنوان IP المحلي لجهاز الكمبيوتر لديك:
   ```bash
   ip -br a || ifconfig
   ```
2. على هاتفك الذكي (المتصل بنفس شبكة Wi-Fi)، افتح الرابط:
   ```text
   https://<عنوان-الـ-IP-المحلي>:3000/phone
   ```
3. وافق على شهادة SSL المحلية المؤقتة في متصفح الهاتف.
4. على جهاز الكمبيوتر، افتح `https://localhost:3000/admin`.
5. اختر منصة تجريبية (مثل طلبية شوبيفاي)، واضغط على زر **Simulate Order & Call**.
6. سيرن هاتفك الذكي بنغمة اتصال، اضغط على **Answer** لبدء التحدث بالدارجة الجزائرية مع وكيل الذكاء الاصطناعي.

---

## 3. اختبار Webhooks المتاجر الحية عبر نفق Cloudflare

لاستقبال إشعارات الطلبيات الحقيقية من متجر شوبيفاي أو يوكان دون رفع الكود إلى استضافة خارجية:

1. شغّل نفق Cloudflare:
   ```bash
   cloudflared tunnel --url http://127.0.0.1:3001
   ```
2. انسخ الرابط المولد (مثل `https://subdomain.trycloudflare.com`).
3. أدخل رابط الـ Webhook في متجرك:
   - **شوبيفاي:** `https://<الرابط>/api/webhooks/shopify`
   - **يوكان:** `https://<الرابط>/api/webhooks/youcan`
   - **ووكومرس:** `https://<الرابط>/api/webhooks/woocommerce`
   - **جداول جوجل:** `https://<الرابط>/api/webhooks/gsheets`
   - **تسيير:** `https://<الرابط>/api/webhooks/tassyir`
4. قم بإجراء طلب تجريبي في متجرك، وسيعترض الـ Playground الطلب تلقائياً، ويطابق العنوان مع ولايات 2026، ويطلق المكالمة الصوتية فوراً!
